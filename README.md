# 🧪 Atlas Químico✨✨

**Atlas Químico** is a web application developed to explore some chemical information through a simple and interactive interface, combining programming and chemistry. 

### ⚗️ Technologies

- **Python**
- **Flask**
- **HTML5 & CSS3**
- **Requests**
- **PubChem PUG REST API**
